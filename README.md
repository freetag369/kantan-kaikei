# かんたん会計(マルチ対応)

個人とビジネス(副業)を切り替えて使えるシンプル家計簿PWAです。
iPhoneのSafariから「ホーム画面に追加」すると、ネイティブアプリのように全画面・オフラインで動作します。

## 機能

- **入力**: 支出/収入の記録(日付・メモ・金額・カテゴリー・支払い方法)
- **カレンダー**: 月間カレンダーに日別の収支を表示、日付タップでその日の取引一覧
- **レポート**: 月間/年間のカテゴリー別内訳(円グラフ)+**支払い方法別集計**
- **予算**: カテゴリー別予算と進捗バー(未設定月は前月から自動引き継ぎ)
- **メニュー**: カテゴリー編集(アイコン・色・並べ替え)、支払い方法管理、取引検索、
  年間/全期間の収支・カテゴリレポート、残高推移、バックアップ(エクスポート/インポート)

### 独自機能

- **個人/ビジネス切替**: 画面上部のピルでワンタップ切替。取引・カテゴリー・予算は完全分離。
  ビジネス側は経費系カテゴリー(仕入・外注費・広告宣伝費など)がデフォルト。
  アクセントカラーも切替(個人=オレンジ / ビジネス=ティール)。
- **支払い方法(カード)**: 現金・クレジットカード・電子マネーなどを自由に登録して取引に紐付け。
  個人/ビジネス共通で使え、レポートで支払い方法別に集計できます。
- **ダークモード**: 端末の外観設定に自動追従。

## データについて

- データはすべて**端末内(localStorage)**に保存されます。サーバーには一切送信されません。
- メニュー → バックアップ から JSONファイルとしてエクスポート/インポートできます。
  機種変更時や念のための定期バックアップをおすすめします。

## 開発・動作確認(Windows)

```bash
python -m http.server 8123
```

- ブラウザで `http://localhost:8123` を開く(開発用: Service Workerは登録されません)
- `http://127.0.0.1:8123` で開くと Service Worker(オフラインキャッシュ)も検証できます

## iPhoneで使う手順

Service Worker と「ホーム画面に追加」の完全な動作にはHTTPSが必要です。
無料のGitHub Pagesに置くのが簡単です:

1. GitHubにリポジトリを作成し、このフォルダの中身をアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
4. iPhoneのSafariでそのURLを開く
5. 共有ボタン(□↑)→「**ホーム画面に追加**」
6. ホーム画面のアイコンから起動すると全画面のアプリとして動作(以後オフラインでも利用可)

## 技術構成

- ビルドツールなしの静的PWA(HTML / CSS / vanilla JS + ES Modules)
- 外部ライブラリ・CDN依存なし(円グラフ等はSVG自前描画)
- `manifest.json` + `sw.js`(Cache First)でオフライン対応
- iOS Safari向け対応: safe-area、100dvh、入力ズーム防止、タッチ最適化
